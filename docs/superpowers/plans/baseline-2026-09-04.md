## iOS

### El pago funciona

`pod install` limpio (`react-native-khipu 2.14.0`, era `2.13.0` en el lock, que estaba desfasado).
`** BUILD SUCCEEDED **`.

La UI de Khipu abre y renderiza completo: fuentes PublicSans, el logo de Khipu en *"Operado por"*,
la imagen del comercio, los colores del tema claro, el título pasado por opciones, y el detalle
del pago con monto y código de operación.

### El retardo de ~1 segundo, medido

Método: se instrumentó `example/src/App.tsx` para pintar la pantalla completa de magenta sólido
justo antes de llamar a `startOperation`, y se capturaron pantallas del simulador cada ~280 ms con
marca de tiempo. El instante de la llamada y el instante en que aparece Khipu se identifican por
el salto de tamaño del PNG: magenta sólido comprime a ~74 KB, la UI de Khipu a ~177 KB.

**La primera corrida se descartó**: los primeros 12 segundos fueron Metro empaquetando en frío
(pantalla negra, *"Bundling 98%..."*). La medición válida es la segunda, con el bundle ya cacheado.

| Frame | ms | bytes | Pantalla |
|---|---|---|---|
| f08 | 2020 | 72932 | "esperando" |
| **f09** | **2369** | 74092 | **marcador magenta — se llamó a `startOperation`** |
| f10 | 2659 | 74092 | marcador |
| f11 | 2928 | 74092 | marcador (verificado visualmente) |
| f12 | 3213 | 74092 | marcador |
| **f13** | **3491** | 109409 | **Khipu empieza a aparecer** |
| f18 | 4967 | 177072 | UI de Khipu estable |

**Cuatro frames consecutivos con el marcador y sin Khipu**, abarcando 844 ms.

- Cota inferior del retardo: `3213 − 2369` = **844 ms**
- Cota superior: `3491 − 2020` = **1471 ms**
- Estimación: **≈1,1 s**

Consistente con el `DispatchQueue.main.asyncAfter(deadline: .now() + 1)` de `ios/Khipu.swift:115`.

**La métrica para comparar después del arreglo es el conteo de frames solo-marcador: hoy son 4.**
Es independiente del intervalo exacto de captura, que varía con la carga de la máquina.

## Android

**El pago funciona.** Compila (`assembleDebug`, 3m13s la primera vez, con descarga de Gradle 8.6
incluida) y la UI de Khipu abre y renderiza igual que en iOS: fuentes, logo, imagen del comercio,
colores del tema y el detalle del pago. `v2.27.0` al pie, que es la versión del SDK Android.
`newArchEnabled=false` — el example corre sobre la arquitectura vieja.

### Lo que costó llegar, porque va a volver a pasar

1. El emulador `Pixel_9_Pro` tenía `/data` al 99% (76 MB libres). Se desinstaló **únicamente**
   `com.khipuexample` —nuestro propio example de una corrida anterior— sin tocar las otras apps de
   Khipu de ese emulador. Liberó 72 MB, insuficiente.
2. Se cambió a `Pixel_9a` (477 MB libres). Tampoco alcanzó: **el APK de debug pesa 162 MB** porque
   incluye las cuatro ABIs (`arm64-v8a` 37 MB, `x86_64` 38 MB, `x86` 39 MB, `armeabi-v7a` 23 MB).
3. **`-PreactNativeArchitectures=arm64-v8a` no reduce el APK.** Esa propiedad gobierna qué
   arquitecturas *compila* el plugin de RN, pero las libs prebuilt del AAR de React Native se
   empaquetan igual. Se verificó: el APK siguió pesando 162 MB con las cuatro ABIs adentro. El
   script `build:android` del example usa esa bandera creyendo que filtra, y no filtra.
4. Lo que sí funciona es `ndk { abiFilters "arm64-v8a" }` en `example/android/app/build.gradle`:
   **162 MB → 62 MB**. Se aplicó de forma temporal solo para poder instalar, y **se revirtió**.

> Vale la pena evaluarlo como mejora aparte del example: un APK de debug tres veces más chico
> instala en emuladores que hoy no tienen espacio. Fuera del alcance de este plan.

5. Un `adb shell am start` sobre `MainActivity` mientras el pago está abierto **mata
   `KhipuActivity`** — el log muestra `onPause`/`onStop`/`onDestroy` seguidos. Para relanzar sin
   matar el pago hay que usar `am force-stop` y después `monkey -c LAUNCHER`. Costó una vuelta
   entera creer que el pago no abría cuando en realidad lo estaba cerrando yo.

```

yarn test       → 1 suite, 1 test (en `todo`)
```

**El repo prácticamente no tiene tests.** `src/__tests__/index.test.tsx` tiene un único test
marcado como `todo`. Vale la pena registrarlo: cualquier afirmación de "los tests pasan" en este
repo dice muy poco, y el test de contrato de claves del Plan 2 sería el primer test real.
